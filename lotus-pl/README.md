# Lotus PL（Vercel 版・Notion 非連携）

タイムカード（lotus-timecard）とデジタルメニュー（lotus-digital-menu）の **API から直接** 打刻と会計を取り込む管理アプリです。Notion には接続しません。

```
タイムカード ──(打刻)──┐
                        ├─▶ このアプリの API ─▶ 専用の保存先（Upstash Redis）─▶ 画面
デジタルメニュー ─(会計)─┘
```

| 画面 | できること |
|---|---|
| 日次計上 | 店舗・日ごとの売上（バック控除後）・会計数・客数・最終レジ金・人件費。スタッフ別の打刻・時間給・バック・給料。打刻とレジ金の修正、計上担当（バックが付く人）の変更 |
| シフト | 月カレンダーで予定を組む（複数スタッフ・毎週繰り返し可）。打刻と照合して「出勤済み・未出勤・予定外」を表示 |
| 給与 | 月のスタッフ別 出勤日数・稼働時間・時間給・各バック・給料、人件費率 |
| 売上 | 月間売上・営業日数・平均日商・来店客数・新規/リピート・客単価・日別グラフ・店舗別内訳 |
| 設定 | スタッフごとの時給（未入力の人は標準の時給） |

## 計算ルール
- **時間給** = 稼働時間 × 時給（設定タブ）
- **バック**（計上担当に付く）= 通常売上×10% + 開店時間以降売上×50% + シャンパン×20% + メダル×¥50
- **計上担当** = 手動で指定した人 ＞ タイムカードの日締め代表 ＞ 最初に出勤した人
- **日次売上** = 通常 + 開店時間以降 + シャンパン − スタッフバック（取消済みの会計は除外）
- **最終レジ金** = スタートレジ金 + 通常 + 開店時間以降 + シャンパン − スタッフバック
- 打刻・レジ金の修正はこのアプリ内だけに保存され、タイムカード側の記録は変わりません（いつでも元に戻せます）

## セットアップ（約10分）
1. このフォルダを GitHub の新しいリポジトリ（例：`lotus-pl`）に push → Vercel で **Add New → Project** から取り込み。
2. Vercel のプロジェクト → **Storage → Create Database → Upstash（Redis）** を作成して、このプロジェクトに接続。
   → `KV_REST_API_URL` と `KV_REST_API_TOKEN` が自動で入ります（無料枠で十分です）。
3. **Settings → Environment Variables** に追加（任意）
   | 変数 | 内容 |
   |---|---|
   | `ADMIN_PIN` | 修正・担当変更・予定・時給の保存に求める PIN（例：デジタルメニューと同じ4桁） |
   | `CRON_SECRET` | 毎日の自動取り込みを外部から叩かれないようにする合言葉（任意の文字列） |
   | `TIMECARD_URL` / `MENU_URL` | URL が変わったときだけ（初期値は今の vercel.app） |
4. **Deploy** → `https://lotus-pl.vercel.app` のような URL が発行されます。
5. iPad / スマホの Safari で開き、共有 → **ホーム画面に追加**。
6. 設定タブで時給を入れる。

## 注意
- タイムカードの API は「その日の打刻」しか返さないため、履歴はこのアプリが取り込んだ日から貯まります（画面を開いたとき＋毎日16:00の自動取り込み）。**使い始めより前の打刻は表示されません**。会計（デジタルメニュー）は過去日もさかのぼって表示されます。
- 営業日の切り替えはタイムカードに合わせています。
- 自動取り込みの時刻は `vercel.json` の `crons`（UTC表記。`0 7 * * *` = 日本時間16:00）。

## ファイル構成
```
index.html / style.css / app.js   画面
api/lotus.js                      画面用 API
api/cron.js                       毎日の自動取り込み
api/_lib.js                       取り込み・保存・計算（バック率 BACK もここ）
vercel.json                       実行時間と自動取り込みの設定
```
